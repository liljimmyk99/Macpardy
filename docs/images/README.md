# Screenshots

Images the top-level [README](../../README.md) expects here. Until a file exists the README
shows a broken image, so drop these in (PNG, retina captures are fine; keep each under ~1 MB).

| File | What to capture | Suggested size |
|---|---|---|
| `hero-display.png` | Display window showing a full board (the hero shot) | ~1720 px wide |
| `editor.png` | Board editor window with a few clues filled in | ~1440 px wide |
| `control.png` | Control window mid-game, on a clue with the timer running | ~1440 px wide |
| `phone-buzzer.png` | `buzzer.html` on a phone, on the buzz screen | ~840 px tall |
| `join-qr.png` | Join screen with the QR code on the Display (⌘J) | ~840 px tall |
| `final-macpardy.png` | Final Macpardy on the Display | ~840 px wide |
| `settings.png` | Settings window (Buzzers tab is a good choice) | ~840 px wide |

Use a game with made-up team names and no personal data. On macOS, ⇧⌘4 then Space then click a
window captures it with its shadow.
